# 야구는 9회말 2아웃부터

고교 3학년부터 드래프트, 프로 시즌, FA, 은퇴까지 진행하는 **야구선수 커리어 시뮬레이션** 웹게임.
모바일 퍼스트, 서버 없이 동작(브라우저 `localStorage`에 저장).

```bash
npm run dev     # http://localhost:3000
npm run build
```

## 게임 루프

```
선수 생성 → 고교 3학년 → 진로 선택(드래프트 / 대학 2년 × 최대 2회) → 신인 드래프트
                                  │  미지명이면 대학으로 재도전
                                  ▼
  ┌──────────────────── 매 시즌 ────────────────────┐
  스프링캠프(훈련) → 전반기 → 올스타 브레이크 → 후반기 → 가을야구 → 시즌 총평
  └──────────────────────────┬─────────────────────┘
                             ▼
        국제대회 → 병역 → 연봉 협상(또는 FA) → 스토브리그(이적 신청)
                             │
                             └→ 다음 해 스프링캠프 … → 은퇴 → 명예의 전당
```

단계가 바뀔 때마다 화면이 전환되고, 시즌 성적은 **시즌 종료 화면에서만** 펼쳐진다.

- **월별 중계 연출** — 전반기(4~7월)·후반기(8~10월)를 **월 단위로 따로 시뮬레이션**해
  한 달씩 재생한다. 그 달의 성적, 상승세/부진 판정, 누적 기록이 순서대로 나오고
  마지막에 올스타 브레이크 / 정규시즌 순위 카드로 끝난다 (건너뛰기 가능)
- **전반기 / 후반기 분할** — 전반기 성적으로 올스타가 갈리고, 후반기 뒤 팀 순위가 정해진다
- **가을야구** — 5위 안에 들면 KBO 방식(와일드카드 → 준PO → PO → 한국시리즈)으로 사다리를 탄다
- **연봉 협상** — 구단 제시액을 수용하거나, 재협상·연봉조정을 걸 수 있다. 실패하면 구단 신뢰가 깎인다.
  FA 이전에는 12억, 이후에는 30억이 한 해 연봉 상한이고 고액일수록 인상률에 제동이 걸린다
- **FA 계약** — 실제 KBO처럼 **총액 = 계약금 + 보장 연봉 + 옵션**으로 제시된다.
  나이가 많고 내구성이 낮을수록 옵션 비중이 커지고(구단이 위험을 나눠 진다),
  옵션은 매 시즌 조건(타자 400타석 + WAR 2.0 / 투수 120이닝 + WAR 1.5)을 채워야 받는다.
  성적이 아쉬우면 **FA 신청을 1년 미루고** 한 시즌 더 뛴 뒤 다시 행사할 수도 있다
- **이적** — 자동 트레이드는 없다. 구단별 영입 관심도를 보고 **직접 신청**한다 (스토브리그당 1회)
- **국제대회 / 병역** — 발탁 통보는 **개막 전**, 대회는 **시즌 중(전반기 직후)** 에 치러진다. 아래 참고
- **부문 타이틀** — 매 시즌 리그 1위 기록을 새로 뽑아 그걸 넘겨야 준다.
  홈런왕·타격왕·타점왕·도루왕·다승왕·평균자책점 1위·탈삼진왕·세이브왕·홀드왕 + MVP·골든글러브·신인왕.
  타이틀은 연봉 협상 배수와 재협상 성공률에 크게 반영된다 (MVP +0.35 · 타이틀 +0.20 · 올스타 +0.05)

## 선수 생성 (4단계)

1. **기본 정보** — 이름·등번호·야수/투수·좌우(투타), 투수라면 **투구폼**
2. **선수 유형** — 교타자·거포·호타준족·수비형 / 파워피처·제구형·기교파·이닝이터
3. **포지션과 희망 구단** — 유형에 맞는 포지션에 "추천" 표시
4. **후보 선수 선택** — 같은 조건으로 뽑은 3명 중 하나

## 시뮬레이션 방식

능력치(0~99)를 **타석/이닝 단위 확률**로 바꿔 한 시즌을 한 번에 계산한다.

- 타자: `BB%`, `K%`, `BABIP`, `타구당 홈런율`을 컨택·파워·선구·주력에서 유도 → 안타/2루타/홈런/도루 배분
- 투수: `K/9`, `BB/9`, `HR/9`, `BABIP`를 구속·제구·변화구·무브먼트에서 유도 → FIP → ERA
- WAR: 타자는 wOBA → wRAA + 수비/포지션 보정, 투수는 RA9 대비 대체 수준

레벨 보정(`LEVEL_ADJ`)으로 고교(+20) / 대학(+12) / 2군(+6) / 1군(0)의 난이도 차이를 만든다.

### 선수 유형은 훈련으로 바뀐다

유형(교타자·거포·파워피처·제구형 …)은 생성 시 고정되는 값이 아니라 **현재 능력치에서 파생**된다.
`deriveStyle()`이 능력치를 z-점수로 정규화해 가장 잘 맞는 유형을 고르므로,
파워피처로 시작해도 제구만 파고들면 제구형으로 바뀌고 스프링캠프에서 "유형 변화" 로그가 뜬다.

### 성장 환경 — 어디서 뛰었는가

한 시즌을 어디서 보냈는지가 다음 겨울 성장 폭을 좌우한다. 원칙 두 가지:

1. **1군은 어느 보직이든 2군보다 불리하지 않다.** 콜업이 손해가 되면 안 된다.
2. 대신 **어린 유망주는 2군에서 가장 빨리 큰다.** 빨리 자라 1군에 올라오라는 구조.

| 환경 | 배수 |
|---|---|
| 2군 (21세 이하) | **×1.40** — 매일 실전, 가장 빠름 |
| 대학 | ×1.25 |
| 1군 주전 / 1선발 / 마무리 | ×1.10 |
| 1군 준주전 / 불펜 | ×1.05 |
| 1군 백업 / 추격조 | ×1.02 |
| 2군 (22~24세) | ×1.00 |
| 상무 | ×1.02 |
| 2군 (25세 이상) | ×0.82 — 나이 먹고 2군이면 정체 |
| 현역 복무 | ×0.60 |

스프링캠프 화면에 지난 시즌 환경과 성장 속도가 표시된다.
이 구조 덕분에 **1군 데뷔 19.3세 · 주전 정착 22~24세**로, 벤치에서 썩는 구간이 짧다.

### 투구폼과 좌우 상대 (플래툰)

투수는 생성 시 **투구폼**을 고른다. 폼에 따라 능력치 배분과 공의 성질이 달라지지만
**총량(OVR)은 같다** — 강해지는 선택이 아니라 성격이 달라지는 선택이다.

| 폼 | 능력치 배분 | K/9 | 피홈런 | 좌우 편차 |
|---|---|---|---|---|
| 오버핸드 | 구속·변화구 ↑ | ×1.07 | ×1.06 | 7% |
| 스리쿼터 | 균형 | ×1.00 | ×1.00 | 12% |
| 사이드암 | 무브먼트·제구 ↑ 구속 ↓ | ×0.90 | ×0.84 | 26% |
| 언더핸드 | 무브먼트 ↑↑ 구속 ↓↓ | ×0.80 | ×0.70 | 34% |

팔이 내려갈수록 삼진은 줄지만 공이 지저분해져 땅볼을 유도하고 피홈런이 준다.
`overall()`도 폼별로 가중치가 달라서(언더핸드는 무브먼트 1.55·구속 0.8) 옆구리 투수가 저평가되지 않는다.

**좌우 편차**는 같은 손 타자에게 강하고 반대 손 타자에게 약한 정도다. 실제로 얼마나 이득인지는 보직이 좌우한다:

- **선발**은 좌우를 가리지 않고 다 상대해야 해서 편차가 큰 폼이 불리하다
- **불펜·마무리**는 감독이 유리한 매치업에 넣어주므로 편차가 곧 무기가 된다
  (우완 언더핸드 마무리 통산 ERA 2.81 / WAR 18.4 — 폼 중 최고)

좌완 투수는 수가 적어 타자가 덜 적응한다는 **희소성 보너스**를 받아, 우타를 많이 상대하는 불리함과 상쇄된다.
타자도 마찬가지로 좌타·스위치가 우완 일색인 마운드를 상대해 이득을 본다.

### 에이징 커브

`player.ts`의 `AGE_PROFILE`은 **능력치마다 다른 피크 나이**를 정의한다. 실제 연구를 따른 것으로,
주력·수비는 20대 중반에 이미 꺾이지만 선구안·제구는 30대 중반까지 계속 좋아진다.

| 능력 | 하락 시작 | | 능력 | 하락 시작 |
|---|---|---|---|---|
| 주력 | 27세 | | 구속 | 28세 |
| 수비 · 내구성 | 28세 | | 스태미나 | 30세 |
| 송구 | 29세 | | 무브먼트 | 32세 |
| 컨택 | 31세 | | 변화구 | 34세 |
| 파워 | 32세 | | 제구 | 35세 |
| 선구 | 35세 | | 멘탈 | 37세 |

`ageFactor(age, trait, key)`는 기준 곡선(19~24세 급성장 → 25~31세 고원 → 32세부터 하락)을
능력치의 피크 나이만큼 평행 이동시킨다. 하락 폭은 `declineMul`과, "가진 만큼 잃는다"는
비례 보정(`floorScale`)을 함께 받는다 — 원래 빠른 선수가 잃을 주력도 많다.

결과적으로 종합 OVR은 **27~30세에 고원을 그리고 31세부터 완만히, 33세부터 가파르게** 떨어진다.

```bash
npx tsx scripts/aging.ts   # 능력치별 나이대별 변화 표
```

### 밸런스 확인

40명씩 6개 유형을 은퇴까지 자동 플레이해 분포를 출력한다.

```bash
npx tsx scripts/balance.ts
```

현재 기준값: 드래프트 OVR ≈ 47, 전성기 OVR ≈ 63(27~29세), 1군 15~16시즌, 은퇴 평균 36세,
1군 데뷔 19.3세 · 주전 정착 22~24세.
레전드급 커리어는 2,700안타 / 440홈런 / 250승 / 350세이브 선.
유형별로 수명이 다르다 — 제구형 선발이 가장 오래 뛰고(평균 37세), 주력에 의존하는 유형이 가장 짧다.

조정 지점: 성장·노쇠는 `ageFactor()` / `AGE_PROFILE` / `grow()`, 은퇴는 `shouldForceRetire()`.

## 국제대회와 병역

4년 주기로 대회가 하나씩 돌아오고, 그중 둘에 병역 혜택이 걸려 있다.

| 연도 (mod 4) | 대회 | 병역 |
|---|---|---|
| 2026, 2030… | 🥇 아시안게임 | **금메달 시 면제** |
| 2027, 2031… | 🏅 프리미어12 | 없음 |
| 2028, 2032… | 🔥 올림픽 | **동메달 이상 시 면제** |
| 2029, 2033… | 🌏 WBC | 없음 |

대표팀 발탁은 OVR·직전 시즌 WAR·인지도로 결정되며, 아시안게임은 병역 미필 20대 선수를 우대한다.
발탁되면 참가/고사를 고를 수 있다.

**28세까지 병역을 해결하지 못하면 입영 통지가 온다.**

- **상무 야구단** — 2시즌 동안 퓨처스리그에서 계속 뛴다. 실전 감각이 유지되고 능력치도 조금 오른다
- **현역 입대** — 2시즌 완전 결장. 돌아오면 주력·구속 같은 신체 능력이 눈에 띄게 떨어진다

자원입대도 가능하다 (24세부터 스토브리그에서 선택).

## 숨은 스탯

- **구단 신뢰** — 활약·수상으로 오르고, 협상 결렬·이적 실패·구설수로 떨어진다. 보직 경쟁과 연봉 제시액에 반영된다
- **동료 관계** — 우승·베테랑 이벤트로 오른다
- **컨디션 / 인지도** — 성적과 이벤트에 반영
