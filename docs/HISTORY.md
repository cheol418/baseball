# 개발 이력

`slbcareer.com`(이번 생은 야구다)을 참고해 시작한 야구선수 커리어 시뮬레이션.
아래는 **무엇을 왜 그렇게 정했는지**와 **어떤 버그를 어떻게 찾았는지**의 기록이다.
같은 실수를 반복하지 않기 위한 문서이므로, 수치보다 판단 근거를 남긴다.

---

## 1. 기반 구축

Next.js 16 + TypeScript + Tailwind. 게임 로직은 React에 의존하지 않는 순수 TS로 분리했다.
저장은 `localStorage` (서버 없음).

**시뮬레이션 방식** — 경기 단위가 아니라 **타석/이닝 단위 확률**로 한 구간을 한 번에 계산한다.
타자는 `BB% · K% · BABIP · 타구당 홈런율`을, 투수는 `K/9 · BB/9 · HR/9 · BABIP`를 능력치에서 유도하고,
WAR는 타자 wOBA→wRAA, 투수 RA9 대비 대체 수준으로 낸다.

첫 밸런싱에서 **전원이 42세까지 20시즌을 뛰며 3,400안타**를 치는 상태가 나왔다.
성장식·노쇠 곡선·은퇴 조건·연봉 상한·등급 스케일을 전부 다시 잡았다.

---

## 2. 에이징 커브 — 능력치마다 다르게 늙는다

사용자가 "30세 일괄 하락은 이른 것 같다"고 했을 때, **조사 결과는 반대였다.**
FanGraphs 기준 피크는 26~29세, 30세 이후 연 -0.5 WAR가 정설이라 30세 하락은 정확하다.

진짜 문제는 **모든 능력을 한꺼번에 꺾는 것**이었다. 그래서 `AGE_PROFILE`로 능력별 피크를 나눴다.

| 능력 | 하락 시작 | | 능력 | 하락 시작 |
|---|---|---|---|---|
| 주력 | 27세 | | 구속 | 28세 |
| 수비·내구 | 28세 | | 스태미나 | 30세 |
| 컨택 | 31세 | | 변화구 | 34세 |
| 파워 | 32세 | | 제구 | 35세 |
| 선구 | 35세 | | 멘탈 | 37세 |

하락 폭은 **"가진 만큼 잃는다"**(`floorScale`)로 비례시켰다. 안 그러면 주력이 38세에 바닥(15)까지 무너졌다.

> **교훈**: 사용자의 체감이 맞는지 먼저 조사한다. 이 건은 체감과 사실이 달랐고, 그걸 말한 뒤에 구조를 고친 게 정답이었다.

## 3. 시즌 구조와 연출

`스프링캠프 → 전반기 → 올스타 → 후반기 → 가을야구`로 재구성.
**표시만 쪼갠 게 아니라 월 단위로 따로 시뮬레이션**해서 진짜 기복이 생기게 했다.

- 전반기 4·5·6·7월(0.60) / 후반기 8·9·10월(0.40)
- 한 달에 1.5초씩 재생하는 중계 연출(`broadcast.tsx`), 건너뛰기 가능
- 시즌 결과는 **시즌 종료 화면에서만** 펼침 (그 전엔 접힌 요약 한 줄)
- 가을야구는 KBO 방식 사다리(와일드카드 → 준PO → PO → 한국시리즈)

## 4. 국제대회 · 병역

4년 주기로 대회가 하나씩 돌고, 둘에만 병역 혜택이 걸린다.

| 대회 | 병역 |
|---|---|
| 🥇 아시안게임 | **금메달 시 면제** |
| 🔥 올림픽 | **동메달 이상 면제** |
| 🏅 프리미어12 / 🌏 WBC | 없음 |

- 발탁 통보는 **개막 전**, 대회는 **시즌 중(전반기 직후)**
- 대회마다 실제 대진(예선→준결승→결승, 3·4위전 포함)과 상대국을 밟는다
- 투수는 모든 경기에 나가지 않는다 — 선발은 3경기 중 1번, 나머지는 "등판 없음"
- 28세까지 미해결이면 **상무(2시즌 퓨처스)** 또는 **현역(2시즌 결장 + 능력치 하락)**

**병역은 돈과 직결된다** — FA 시장가에 미필은 ×0.82(군 공백 위험), 메달은 개당 +4%.

## 5. 성장 환경 — 어디서 뛰었는가

사용자 요구가 두 개였고 서로 당기는 방향이었다:
"1군 벤치가 2군보다 느려선 안 된다" + "어릴 땐 2군에서 빨리 커서 1군에 올라왔으면".

해법은 **나이 조건부**다.

| 환경 | 배수 |
|---|---|
| 2군 (21세 이하) | **×1.40** |
| 대학 | ×1.25 |
| 1군 주전 | ×1.10 |
| 1군 백업 | ×1.02 |
| 2군 (22~24세) | ×1.00 |
| 2군 (25세 이상) | ×0.82 |
| 현역 복무 | ×0.60 |

1군은 어느 보직이든 2군 이상이고, 가속은 유망주에게만 걸린다.

## 6. 투구폼 · 좌우 플래툰

투구폼 4종은 **능력치 배분만 바꾸고 총량(OVR)은 같다.** 강해지는 선택이 아니라 성격이 달라지는 선택.

| 폼 | K/9 | 피홈런 | 좌우 편차 |
|---|---|---|---|
| 오버핸드 | ×1.07 | ×1.06 | 7% |
| 스리쿼터 | ×1.00 | ×1.00 | 12% |
| 사이드암 | ×0.90 | ×0.84 | 26% |
| 언더핸드 | ×0.80 | ×0.70 | 34% |

`overall()`도 폼별 가중치를 쓴다(언더핸드는 무브먼트 1.55·구속 0.8). 안 그러면 옆구리 투수가 OVR 36으로 저평가됐다.

**좌우 편차의 이득은 보직이 결정한다** — 선발은 좌우를 다 상대해 불리, 불펜은 매치업을 골라 써서 무기가 된다.
(우완 언더핸드 마무리 통산 ERA 2.81 — 폼 중 최고)
좌완에는 희소성 보너스(+1.8)를 줘서 우타를 많이 상대하는 불리함과 상쇄시켰다.

## 7. 이벤트 체인

참고 사이트 번들에서 `sourceEventKey`, `FIRST_CALLUP_STAYED`, `INJURY_RETURN_PLAN` 같은 키를 발견했다.
**선택이 즉시 끝나지 않고 1~2시즌 뒤 결과로 돌아오는 구조**가 그쪽의 핵심이었다.

우리 구현: `첫 콜업 적응` · `재활 계획` · `포지션 전환` · `커리어 전환점`.
커리어당 평균 2.9종을 겪고, 선수 탭에 "진행 중: 재활 계획 — 2033년 결과"로 남는다.

## 9. 야구팬용 요소

- **대기록** — 노히트 노런·퍼펙트·사이클링 히트·한 경기 4홈런·연속 안타 (커리어당 0.7회)
- **통산 이정표** — 1,000안타 / 300홈런 / 200승 / 300세이브 … (커리어당 7.8회)
- **역대 순위** — 가상 KBO 역대 10걸과 대조, 1~3위는 금색
- **별명** — `대투수` `닥터 K` `잠수함` `수호신` `거포` `국민 타자` … (78%가 획득)
- **영구결번 / 은퇴식** — 한 팀 10시즌 + 비중 62% + HOF 380점이면 영구결번
- **구장 효과** — 대구 팔공 파크(홈런 공장) ↔ 서울 한강 스타디움(투수 무덤), 같은 기량도 OPS 35포인트 차
- **트레이드 데드라인** — 올스타 브레이크에 우승 도전팀이 손을 내민다

## 11. 1군 입지 세분화

"1군 선수"를 한 덩어리로 두니 팀 안에서의 위치가 드러나지 않았다.
간판타자와 백업이 같은 `주전`/`백업` 라벨 두 개로만 갈리는 건 실제 구단 운영과 거리가 멀다.

보직을 **티어 0~6**으로 나누고 `roles.ts` 하나에 모았다.

| 티어 | 타자 | 선발 | 구원 |
|---|---|---|---|
| 6 | 간판타자 | 에이스 | — |
| 5 | 핵심타자 | 1선발 | 마무리 |
| 4 | 주전 | 선발 | 필승조 |
| 3 | 준주전 | 5선발 | 불펜 |
| 2 | 백업 | — | 추격조 |

핵심은 **판정을 한 곳에 모은 것**이다. 그 전에는 `role.includes("선발")`,
`["주전","1선발","선발","마무리"].includes(role)` 같은 문자열 비교가 6개 파일에 흩어져 있었다.
`에이스`를 추가하는 순간 `includes("선발")`이 false가 되어 선발이 불펜으로 계산될 뻔했다.

입지는 라벨이 아니라 **실제로 무언가를 바꾼다** — 연봉 협상 가중치, 이적 시 원소속팀이 놓아주는 정도,
시즌 목표의 난이도, 훈련 효율(간판 1.24배 ↔ 백업 0.94배), 팬 반응.

> **교훈**: 문자열로 분기하는 개념이 3곳 이상에 나타나면 그때가 모듈로 뺄 시점이다.
> 값을 하나 추가하려다 흩어진 비교문이 조용히 틀리는 걸 그때 발견하게 된다.

## 12. 시즌 목표 — 유형·포지션·보직별로

**"OPS .841인데 목표 «OPS .820» 미달"** 신고에서 출발했다.
원인은 396타석으로 규정타석(400)을 못 채운 것이었는데, 화면에는
"OPS .820에 미치지 못했습니다"라고 **사실과 다른 사유**가 찍혔다.

두 가지가 동시에 틀려 있었다.

1. 판정 함수가 `boolean`만 반환해 UI가 목표 라벨로 실패 문구를 조립했다 → `{met, reason}`으로 바꿔 실제 사유를 돌려준다
2. 준주전(출장 비중 0.66 → 최대 ~400타석)에게 400타석 목표를 배정했다 → 구조상 도달 불가

이어서 목표 자체를 **유형·포지션·보직별로** 나눴다. 거포는 홈런·타점·장타율, 교타자는 타율·안타·출루율,
호타준족은 도루와 호타준족 달성, 이닝이터는 이닝, 탈삼진형은 K, 제구형은 WHIP·볼넷.
센터라인(C·SS·2B·CF)은 수비 부담만큼 타격 요구를 낮추고, DH·1루수는 반대로 올렸다.
간판·에이스에게는 WAR 5.0, OPS .900, 평균자책 3.00 같은 리그 정상급 목표가 따로 간다.

기준선은 **눈대중이 아니라 실측 분위수**로 잡았다. `statdist.ts`로 보직별 시즌 기록 분포를 뽑고
대략 60~70번째 백분위에 문턱을 놓았다.

이 과정에서 **도루 상한이 리그 전체 15개**인 것을 발견했다. 호타준족 주전의 도루 중앙값이 6개였고,
`25도루` 목표는 200시즌 중 0번 달성됐다. 도루 시도율 계수가 실제 KBO의 3분의 1이었다.

> **교훈**: "달성률 0%"인 목표는 목표가 어려운 게 아니라 **시뮬레이션이 그 수치를 못 만든다**는 신호다.
> 문턱을 내리기 전에 분포를 먼저 본다.

## 13. 이적 시장 — 무엇이 몸값을 정하는가

**"이거 너무 과하다"** — 2군 주전(OVR 74)이 9개 구단 전부에서 관심도 99, 성사 63%를 받는 화면.

측정해보니 더 심했다. **직전 시즌 WAR −0.1의 백업**조차 9개 구단 중 8곳이 관심 70 이상,
성사 88%였다. 원인은 둘이었다.

- 기준선이 OVR 58이라 어지간한 1군 선수면 기본 점수가 이미 만점권
- **나이·연봉·포지션이 계산에 아예 없었다**

기준선을 1군 주전(OVR 76)으로 올리고 네 축을 추가했다.

| 축 | 반영 방식 |
|---|---|
| 나이 | 25세 이하 +5 → 30세 −12 → 34세 −36 (남은 전성기의 길이) |
| 연봉 | 그 구단 자금력 대비 부담. 부자 구단은 같은 연봉도 덜 부담스럽다 |
| 포지션 | C +8 · SS +6 ↔ 1B −6 · DH −9 (대체 난이도) |
| 입지 | 원소속팀은 간판선수를 내주지 않는다 (성사 확률 −0.18) |

결과적으로 "관심은 높지만 놓아주지 않는" 상황이 생긴다. OVR 90 스타는 전 구단이 관심 99를 보이지만
성사는 38~47%다. FA가 탈출구 역할을 하게 되어 의도한 구조다.

> **교훈**: "너무 과하다"는 신고를 받으면 신고된 화면 하나가 아니라 **전 구간 분포**를 찍는다.
> 이 건은 2군 선수뿐 아니라 모든 구간이 포화였고, 화면은 증상이지 원인이 아니었다.

## 14. 연봉 — 인상률에는 수렴점이 없다

"연봉이 좀 과한 것 같다"는 신고. 재보니 **커리어 최고 연봉의 중앙값이 정확히 상한(15억)** 이었다.
160명 중 104명이 10억 이상. 27~32세 상위 25%가 전부 캡에 붙어 있었다.

처음엔 인상률을 깎았다(WAR 계수 0.30 → 0.22, 수상 가중치 축소). **오히려 늘었다.**
저연봉 구간 가속을 같이 넣은 탓도 있지만, 진짜 이유는 구조였다.

> 연봉 = 직전 연봉 × 인상률 은 **수렴점이 없는 곱셈**이다.
> 평균 인상률이 1.1이기만 해도 15시즌이면 4배가 되고, 결국 전원이 상한에 도달한다.

그래서 **적정 몸값으로 끌어당기는 항**을 넣었다. `marketValue()`(최근 WAR·OVR·나이·인지도 기반)의
절반을 기준점으로 삼고, 직전 연봉에서 출발한 금액을 그쪽으로 당긴다. 당기는 비율은 연차에 비례한다
(저연차는 직전 연봉 중심, 고연차는 시장가 중심).

이제 과대평가된 선수는 자연히 깎이고 저평가된 선수는 오른다. 커리어 최고 연봉 중앙값 **15억 → 5.5억**,
나이 곡선도 27~31세 피크 후 하락으로 실제 KBO를 닮았다.

> **교훈**: 매년 곱해지는 값에 상한만 씌우면 전원이 상한에 모인다. **수렴점을 만들어야** 분포가 생긴다.

## 15. 은퇴, 그 이후

### 은퇴 권고

기존에는 방출(강제)뿐이었다. 참고 사이트처럼 **거부할 수 있는 권고**를 넣었다.
34세부터 기량·입지·전성기 대비 하락폭을 보고 권하며, 뿌리치면 구단 신뢰와 인지도가 깎인다.

처음 넣었을 때 평균 은퇴 나이가 36.9 → **35.2세**로 당겨졌다. 권고 조건이 한 살씩 일렀다.
나이 게이트를 전부 한두 살 올려 36.0으로 되돌렸다.

### 명예의 전당 헌액 투표

은퇴 5년 뒤부터 최대 10차, 득표율 75% 기준. 실제 기자단 투표처럼 첫 해에는 표가 갈리고
해가 갈수록 재평가된다(단, 첫 득표가 낮으면 오히려 떨어진다).

| 통산 등급 | 헌액률 | 평균 |
|---|---|---|
| 레전드 | 100% | 1차 |
| 명예의 전당 | 89% | 3.2차 |
| 프랜차이즈 스타 이하 | 0% | — |

경계가 뚜렷한 게 중요하다. 아무나 들어가면 전당의 의미가 없다.

### 은퇴 후 진로

코치·감독·해설위원·스카우트·프런트·야구 아카데미·야구를 떠나다 7종.
자격 조건(시즌 수·인지도·통산 점수)과 **적합도**가 따로 있어, 아무 길이나 고르면 평범하게 끝난다.
감독은 멘탈과 우승 경험, 해설은 인지도, 스카우트는 멘탈과 경력이 적합도를 만든다.

## 16. 선수 유형 확대

타자 4종 → 10종, 투수 4종 → 8종.

- **타자** 교타자 · 출루형 · 거포 · 중장거리형 · 호타준족 · 대도 · 수비형 · 강견형 · 철인형 · 해결사
- **투수** 파워피처 · 제구형 · 기교파 · 땅볼유도형 · 이닝이터 · 탈삼진형 · 노련형 · 고무팔

유형을 늘리자 `deriveStyle()`(현재 능력치로 유형을 역산)이 **가중치를 크게 준 유형으로 쏠렸다.**
z-score에 곱하는 가중치의 크기가 클수록 점수가 커지는 구조라, `대도`(주력 17)가 부당하게 유리했다.
가중치 벡터를 **단위 길이로 정규화**해 해결했다.

통산 기록이 실제로 갈린다 — 거포 290홈런·36도루 ↔ 대도 136홈런·168도루,
탈삼진형 2,021K ↔ 땅볼유도형 1,750K.

**남겨둔 것**: 호타준족·이닝이터처럼 능력이 고른 "균형형"은 훈련 후 유형 유지율이 0~5%다.
z-score 편차가 작아 어떤 유형에도 강하게 걸리지 않기 때문. 다만 "훈련에 따라 유형이 바뀐다"는
기존 설계와 일관되므로 **의도적으로 그대로 둔다**(2026-09-13 사용자 확인).

## 17. 진로 선택 — 고졸이 갈림길이 되게

"신인 드래프트를 고르면 확률이 변하나?"라는 질문에 답하려고 측정했다가 문제를 찾았다.

| | 고졸 직행 (수정 전) | 대학 진학 |
|---|---|---|
| 중앙 지명순위 | 66순위 | 20순위 |
| 1라운드 | **200명 중 1명** | 58명 |

대학이 일방적으로 우월해 **갈림길이 갈림길이 아니었다.** `draftScore()`가 현재 능력치만 보니
2년 덜 자란 고졸이 이길 수 없는 구조였다.

실제 스카우트는 **나이 대비 성장 여지**를 본다. 어릴수록 잠재력 가중치를 높이고(0.20 → 0.28)
나이 보너스를 더했다. 여기에 **어린 선수일수록 평가 편차가 크게**(지명 점수 노이즈 3 → 5.5) 만들어
대박도 쪽박도 고졸에서 나오게 했다.

| | 고졸 직행 (수정 후) | 대학 진학 |
|---|---|---|
| 중앙 지명순위 | 22순위 | 20순위 |
| 1라운드 | 23% | 29% |
| 입단 시 | 19세 · OVR 49 | 22세 · OVR 61 |

순위는 비슷해지고 차이가 **"3년 일찍 시작" vs "완성도 +12"** 로 바뀌었다. 이제 선택이다.

> **교훈**: 선택지가 둘인데 한쪽이 항상 우월하면 그건 선택지가 아니다.
> 갈림길을 넣었으면 **양쪽 결과 분포를 찍어** 실제로 갈리는지 확인한다.

### 뒤이어 드러난 것 — 성적이 지명에 거의 반영되지 않았다

"타율 .261 · 2홈런 · WAR −0.2인데 2~3라운드는 과하다"는 신고로 다시 열어봤다.
`draftScore`의 성적 항이 이랬다.

```
perf = (ops - 0.75) * 30 + hr * 0.4
```

OPS .726이면 **+0.08**. 툴(OVR·잠재력)이 58점을 차지하는데 성적은 사실상 0점이었고,
WAR은 아예 들어가지 않았다. 스카우트가 성적표를 안 보는 셈이다.

리그 평균(고교 OPS .70) 대비로 폭을 넓히고 WAR을 넣자 예상 라운드가 성적을 따라갔다.

| OPS | 1.08 | .80 | .75 | .70 | .64 | .41 |
|---|---|---|---|---|---|---|
| 예상 | 1R 상위 | 1R | 2~3R | 4~6R | 7~9R | 미지명 |

> **교훈**: 여러 항을 더해 점수를 내면 **각 항이 실제로 몇 점을 움직이는지** 찍어본다.
> 있는 줄 알았던 항이 ±1점짜리라 없는 것과 같을 수 있다.

## 18. 후보 선택이 선택이 아니었다

생성 화면의 후보 3인 중 OVR이 낮은 쪽을 고를 이유가 없었다. 상관계수를 재보니 이유가 나왔다.

| | 상관 |
|---|---|
| OVR ↔ 재능 | **+0.52** |
| OVR ↔ 잠재력 | **+0.56** |

| OVR 구간 | 평균 재능 | 평균 잠재 OVR |
|---|---|---|
| ~40 | 67 | 83.3 |
| 47+ | 82 | 92.2 |

`talent`가 시작 능력치(`(talent−1)×14`)와 잠재 여유(`talent×26`)를 **둘 다** 올리고 있었다.
그래서 OVR이 낮은 후보는 재능도 잠재력도 낮은 "그냥 나쁜 선수"였다. 트레이드오프가 아니라 우열이었다.

후보를 **완성도 ↔ 성장 여지 축**(`bias`)에 의도적으로 배치했다.

| 후보 | 시작 OVR | 잠재 OVR | 재능 | 성장 여지 |
|---|---|---|---|---|
| 완성형 | 49.1 | 81.0 | 63 | 31.9 |
| 균형형 | 43.8 | 87.8 | 76 | 44.0 |
| 원석형 | 39.0 | 96.1 | 91 | 57.1 |

> **교훈**: 후보를 각각 독립적으로 뽑으면 좋은 놈은 모든 면에서 좋고 나쁜 놈은 모든 면에서 나쁘다.
> 선택지로 만들려면 **축을 정하고 그 위에 일부러 배치**해야 한다.

## 발견하고 고친 버그들

기록해둘 가치가 있는 것만.

| 버그 | 원인 | 교훈 |
|---|---|---|
| **고졸 미지명 무한 루프** (2426년·418세) | 미지명 → 진로 선택 → 재신청 고리에서 매번 나이만 증가 | 상태 머신에 순환 경로가 없는지 전수 테스트 필요 |
| **대표팀이 한 번도 안 뜸** | OVR 스케일을 바꾸고 대회 문턱(66~72)을 안 옮김 | 스케일 변경 시 기준선 전부 이동 |
| **올스타 15%밖에 안 됨** | 같은 원인 + 선발 이닝이 적어 WAR가 안 쌓임 | 지표가 이상하면 입력값(이닝)부터 본다 |
| **집중 훈련했는데 안 오름** | 잠재력에 도달한 능력이 `clamp`에 걸림 | 후보를 성장 여지 기준으로 뽑게 수정 |
| **지옥 훈련이 밸런스보다 약함** | 대상 2개 vs 전체 8개라 총합이 밀림 | 대상을 여지 상위 3개로 확정, 1500건 전수 검증 |
| **OVR 변화가 항상 `63 → 63`** | 스냅샷을 캠프 훈련 *이후*에 찍음 | 비교 기준 시점을 명확히 |
| **능력치 상한이 99처럼 보임** | 로직은 120인데 막대를 0~100으로 그림 | UI 스케일도 상수를 따르게 |
| **병역 면제인데 "복무중"** | 조건이 `!== PENDING && !== DONE`이라 EXEMPT도 통과 | 열거형은 화이트리스트로 비교 |
| **구버전 세이브 크래시** | `intlResults` 없는 세이브에서 `.filter` | 저장소 경계에 마이그레이션 배치 |
| **측정값이 전부 거짓** | 새 phase를 `autoplay.ts`에 안 가르쳐 조기 은퇴 | 스크립트도 코드의 일부다 |
| **국제대회·올스타전 타자 기록이 항상 0** | 한 경기는 4타석인데 `pa < 5`면 빈 기록 반환 | 시즌용 소표본 가드가 단일 경기를 죽였다 |
| **모든 국제대회 타율이 정확히 `.250`** | 4타석에 기댓값 반올림 → 언제나 1안타 | 표본이 작으면 반올림이 아니라 **추첨**해야 한다 |
| **프리미어12가 7월에 열림** | 대회 종류와 무관하게 전반기 직후 일괄 실행 | 일정이 있는 이벤트는 개최 시점을 데이터로 갖는다 |
| **올스타전 경기가 선정 발표보다 먼저 재생** | 중계 step 배열에 경기를 먼저 push | 연출 순서도 인과를 따라야 한다 |
| **목표 미달 사유가 사실과 다름** | 판정이 `boolean`만 반환, UI가 라벨로 문구 조립 | 판정 함수가 **이유까지** 돌려준다 |
| **시즌이 145경기** | 월별로 따로 반올림해 합계가 어긋남 | 구간 분할은 비율이 아니라 **누적 차분**으로 |
| **리그 전체 도루 최대 15개** | 도루 시도 계수가 실제의 1/3 | 달성률 0%인 목표는 문턱이 아니라 분포를 의심 |
| **연봉이 전원 상한에 고착** | 인상률 곱셈에는 수렴점이 없다 | 상한 대신 **적정값으로 당기는 항**을 넣는다 |
| **유형이 특정 하나로 쏠림** | z-score에 곱하는 가중치 크기가 클수록 유리 | 벡터 비교 전에 정규화 |
| **고졸이 1라운드에 못 감** (200명 중 1명) | 드래프트 점수가 현재 능력치만 봄 | 두 선택지의 결과 분포를 찍어 갈리는지 확인 |
| **가을야구 화면 크래시** | 구버전 세이브의 `rounds[].line` 부재 | 중첩 구조에 필드를 더하면 마이그레이션도 중첩까지 |

## 참고 사이트 대비

**우리가 더 깊은 것** — 능력별 에이징 커브, 투구폼·플래툰, 월별 중계, 성장 환경, 잠재력 불확실성,
구단 시즌 목표(유형·포지션·보직별), 대기록·역대 순위, 구장 효과, 이적 신청제(나이·연봉·포지션 반영),
FA 계약 구조(총액/계약금/옵션), 연봉협상 3택, **1군 입지 6단계**, **은퇴 후 진로와 명예의 전당 투표**.

참고 사이트에는 **은퇴 권고**가 있어 가져왔다 — 다만 우리 쪽은 뿌리치고 더 뛸 수 있게 했다(대가는 신뢰 하락).

**참고 사이트에 있고 우리에게 없는 것** — **온라인 기능**(전체 랭킹·신인왕 경쟁·댓글·좋아요·공개 선수 페이지·팀 로고).
서버가 필요해 성격이 다른 작업이다.

**조사해서 알아낸 것**: 참고 사이트의 `희망 구단`은 지명 시 **40% 고정 확률**로 반영되고,
`출신 고등학교`는 대회 결과 해시 시드에 들어가지 않는 **순수 장식**이다(상대 학교 목록에서 자기 이름만 제외).
